### Localization

Using .csv to manage multiple languages, check the example assets/translations/langs.csv.
The first line is the list of support language.
Each line has a key and list of values for each language, split by ",".
For text that contains ",", wrap it in "...".

### Json parsing / serialization

This project is implementing [json_serializable](https://pub.dev/packages/json_serializable). It use build_runner to
generate files. If you make a change to these files, you need to re-run the generator using build_runner:

```
flutter pub run build_runner build
```

generator using build_runner and remove conflict file :

```
flutter packages pub run build_runner build --delete-conflicting-outputs
```

# Resources
Images, String, Fonts can be accessed through the resource class (R) that was generated by gen_res.
```
R.image.photo
R.string.text
R.string.textWithArg(args: ['arg'])
R.font.roto
```
Styles, Dimens,.. can be use by the similar way but need to define manually.
Colors can be generated by gen_res, but need to create color.xml file and enable generate color.g.dart file in pubspec.yaml.

After update a resource, run "dart run gen_res" from terminal or run flutter pub run build_runner build to re-generate resource config.
For more info about this, please check https://github.com/nguyenvantuyen98/gen_res
